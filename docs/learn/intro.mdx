# Inkshelf, explained

<OneSentence>
Inkshelf is an app for a PocketBook e-reader that reads comics, books and recipes from your own
servers, written in pure Go, and drawing on the e-ink screen by itself, without the vendor's
SDK.
</OneSentence>

This site explains how it works, from the first pixel to the last page. You need to know how to
program. You do not need to know anything about e-readers, EPUB or Go's internals: every idea is
introduced before it is used.

## What Inkshelf does

An e-reader is a small computer with a screen of <Term id="eink">e-ink</Term>: paper-like, easy
on the eyes, and very slow. The one Inkshelf runs on is a PocketBook InkPad 3: a screen
of 1404 × 1872 pixels, 16 shades of gray, a modest ARM processor.

Inkshelf connects that reader to three kinds of <Term id="server">server</Term> you may run at
home:

- **Komga**, a server of comics and manga, which sends a comic page by page as pictures;
- **Calibre-Web**, a server of books, which sends a whole <Term id="epub">EPUB</Term> (or a CBZ
  of comic pages);
- **Mealie**, a server of recipes, whose recipes Inkshelf lays out into pages.

You pick a book, it downloads, and you read it. Your progress goes back to the server, so another
device opens the book where you left it.

## Why it is interesting

Most PocketBook apps are written in C against PocketBook's SDK, a library called `libinkview`
that draws, refreshes the screen and reads the buttons for them. Inkshelf uses none of it. It is a
plain Go program with no C code at all (no <Term id="cgo">cgo</Term>), so one command builds it on
any computer:

```sh
make build   # CGO_ENABLED=0 GOOS=linux GOARCH=arm GOARM=7 go build … -o build/inkshelf.app ./cmd/inkshelf
```

So everything the SDK did, Inkshelf does itself, and that is what this site shows:

- it writes pixels straight into the screen's memory, the <Term id="framebuffer" />, and asks the
  panel to refresh with an <Term id="ioctl" />;
- it talks to the reader's firmware through Linux <Term id="ipc">IPC</Term>, to learn when it is
  in front, when Wi-Fi is up, and to receive taps and keys;
- it opens EPUB files and lays out their text itself: CSS, line breaking, hyphenation,
  justification, pages;
- it turns a color comic page into the panel's 16 grays, once, when the book downloads.

## What you need to know

Nothing about e-readers. Some programming, in any language: Go code is shown in short snippets, and
they read like most C-family languages. When a Go idea matters (a <Term id="goroutine" />, a
<Term id="mutex" />), the site explains it.
